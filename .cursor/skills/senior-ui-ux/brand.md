## Type scale (ops density)

- Page title: 20–24px, weight 600
- Section: 16px, weight 600
- Body / table: 14px, weight 400
- Meta: 12px, muted

Line length in forms ≤ ~70 characters. Tables use the full work area.

## Do not

- Hero full-screen videos or Bootstrap marketing cards
- Centered sparse landing layouts inside signed-in pages
- The leftover “Talal Logistics” name
- Pure black `#000` on primary blue for small text (contrast)
